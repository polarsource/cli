# Polar CLI

A Polar CLI for your terminal.

- Migrate from Lemon Squeezy, Paddle & Stripe
- Tunnel Webhooks to your local environment
- Initialize Polar boilerplate with a single command
- And much more...

Currently in development.

## Homebrew

Homebrew tap publishing and first-release setup are described in
[docs/homebrew.md](docs/homebrew.md). Once the tap's initial formula is published,
install with `brew install polarsource/tap/polar`.
